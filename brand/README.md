# Identitas BALANCE

Simbol B menggunakan bentuk geometris dengan jalur horizontal yang mengacu pada tiga aliran distribusi. Wordmark menggunakan warna biru #2864F0 dan navy #101A2E yang sudah ada pada desain dasbor.

- balance-symbol.svg: simbol vektor transparan untuk aplikasi, dokumen, dan rekaman.
- balance-symbol.png: ekspor transparan 1200 px.
- balance-wordmark.svg: simbol dan nama BALANCE.
- balance-wordmark.png: ekspor transparan untuk video/presentasi.

Konsep awal dibantu image generation; aset akhir disusun ulang sebagai geometri SVG dan diekspor ke PNG untuk ketajaman pada ukuran kecil. Tidak menggunakan logo institusi atau merek pihak lain. Font pada wordmark memakai Arial/sans-serif; jika dipindahkan ke perangkat desain, periksa fallback font.

Di aplikasi, simbol dipasang pada lokasi penanda merek sidebar dan halaman masuk; favicon memakai versi latar navy. Susunan layout dan palet warna dasar teman tim dipertahankan. Ikon navigasi adalah gambar garis SVG dalam source, menggantikan karakter Unicode yang sebelumnya tidak konsisten antarperangkat.
